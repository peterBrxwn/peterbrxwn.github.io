Lead engineer

Ping44 ping44.com ↗

Real-time multiplayer party games on the web, iOS and Android. Create a room, share a link and play with up to 100 people, with voice chat built in.

  • A Go server owns every rule and all game state (in Redis); the React web client and Flutter app only display what it sends over Socket.IO.
  • The server draws each game's screens in the Flutter app, so a new game ships without an app-store release.
  • Word games, trivia, drawing, cards (WHOT, UNO, Poker, Blackjack) and board games, with voice chat over Agora.
  • Monitored with Prometheus, Grafana and Alertmanager, and covered by unit, integration and end-to-end tests.
  • 17 games live
  • 100 players per room
  • 3 platforms

Lead engineer

OrangeFen orangefen.com ↗

A marketplace where businesses pay people for small tasks: sharing a launch, making a video, trying a product. Workers submit proof and get paid when it's approved.

  • Four roles with their own tools: workers, reviewers (paid per review), advertisers (campaigns, budget stats, API keys) and admins.
  • Money is stored in minor units end to end, and balances live in an append-only, idempotent ledger.
  • The browser talks only to the Go API: sign-in, uploads and storage are proxied through it, with rate limiting and strict upload checks.
  • Supabase Postgres with row-level security that denies by default; runs as a container on AWS Lightsail.
  • Go

  • Supabase

  • TypeScript
  • Tailwind
  • Docker
